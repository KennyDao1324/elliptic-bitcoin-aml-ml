# Elliptic Bitcoin dataset

- Publisher: Elliptic with the MIT-IBM Watson AI Lab
- Canonical source: https://www.kaggle.com/datasets/ellipticco/elliptic-data-set
- Research paper: Weber et al., *Anti-Money Laundering in Bitcoin* (2019)
- Type: real, anonymized Bitcoin transaction graph
- Licence listed by the canonical distribution: CC BY-NC-ND 4.0

Expected files are `elliptic_txs_features.csv` and `elliptic_txs_classes.csv` under `data/raw/`. Raw and processed rows are not redistributed. Verify the canonical terms before sharing any derivative artifact.
